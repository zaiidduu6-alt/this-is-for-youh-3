MUSKUUU APOLOGY WEBSITE - GitHub Pages (all files in the root, no folders)

FILES: index.html, style.css, script.js, music_trimmed.mp3, sticker-*.png (4), og-image.jpg (link preview), README.txt

1) Create a GitHub repo and upload ALL these files to the repo root.
2) Settings > Pages > Deploy from branch > main / (root). Your link will be:
   https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/
3) IMPORTANT for the link preview (WhatsApp/Instagram need a full web address):
   open index.html and replace  https://zaiidduu6-alt.github.io/this-is-for-youh-3/  in 4 places (already done for your link)
   (canonical, og:url, og:image, twitter:image) with your real link. Keep "og-image.jpg" at the end of the image URLs.
4) Previews are cached by WhatsApp/Instagram. If you see a blank card, wait a while or share the link with ?v=2 at the end.

MUSIC: music_trimmed.mp3 starts from 0:00 every time the page opens and loops until the page is closed.
Some browsers (mostly iPhone/Safari and in-app browsers) refuse sound before any touch; in that case the song
starts from the beginning on the very first tap/click anywhere - no button needed.

Messages live in script.js (MSG list). Pictures: sticker-*.png. Preview image: og-image.jpg (1200x630, a real render of page 1).
